## 시안과 의도적으로 달라진 점
- 하단 메뉴: 홈·데일리·큐레이팅·저장·프로필 → **홈·장소·내 약속·저장·프로필** (파일럿 제안, D01 승인 필요). 데일리는 홈에서 진입.
- 장소 카드/상세: 평점·리뷰 수·'영업중' 표시 제거 → 영업시간 텍스트 + **정보 확인일**. 사진은 색 자리표시. 상호는 가상.
- 상세 탭: info/menu/cited/review → **정보/메뉴**만. 지도 이미지 대신 외부 지도 링크(역 기준), 주소 복사.
- 데일리: 사용자 계정·팔로우·좋아요/댓글 수 제거 → '첫, 길 운영팀' 글, 연결 장소 저장, 링크 공유.
- 프로필: 좋아요 수·게시물 그리드 제거 → 실제 저장 수, 신청 상태, 닉네임 수정, 데모 초기화.
- 홈: 시안의 아이콘 10칸 중 동작하는 8개(맛집·카페·고급·바·분위기·지역·데일리·저장)만 둠. 'TOP50' → '지금 뜨는 장소'(순위 표기 없음). 알림 종 숨김.
- 매칭 1단계: '이름' → **닉네임**(실명 받지 않음). 태어난 연도는 자기 신고값이며 인증 아님.
- 강조색: #EF5FB4. 작은 글씨는 대비를 위해 #C2338A 사용.
- 4단계 만남 템포: '채팅 후 결정' → **'일정 확인 후 결정'** (ROADMAP: 채팅 후순위). 나이 범위 20~45세, 기본 25~35세.
- 다음 버튼: 미완성 시 회색이지만 누를 수 있으며, 누르면 해당 필드에 오류를 표시.
- 상단 알림(종) 아이콘: 알림 기능이 없어 숨김.
- 영문 온보딩(02)·헤더(03)·후기(08): 이번 범위 아님.

## 미확정 가정값
파일럿 역 목록(성수·뚝섬·건대입구·왕십리·서울숲), 시간대 4종, 한 줄 소개 80자·자기소개 500자, 예산 상한 20만원, 날짜 최대 6일,
닉네임 12자, 신청 가능 나이 만 20~45세, 취미 9종·선호 장소 6종 선택지.
날짜·시간대 조합: '평일 저녁'은 월~금, 주말 시간대는 토·일 날짜에만 적용 (공휴일은 아직 평일로 취급).
