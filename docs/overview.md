# 첫, 길 서비스 개요

## 한 줄 소개
운영자가 첫 만남을 소개하고, 두 사람이 시간과 장소를 고르면 예약까지 연결하는 서비스입니다.

## 형태
모바일 웹 (화면 폭 320~430px 기준)

## 지금 있는 기능 (MVP 단계 0~1)
| 화면 | 경로 | 내용 |
|---|---|---|
| 홈 | `/home` | 바로가기, 매칭 신청 배너, 맞춤 추천, 지금 뜨는 장소, 동네별·테마별·카테고리별 장소, 진행 방식·파일럿 가격 |
| 장소 | `/places`, `/places/[id]` | 장소 목록과 상세(정보·메뉴 탭), 저장 |
| 데일리 | `/daily` | 운영팀 글, 연결 장소 저장, 링크 공유 |
| 저장 | `/saved` | 저장한 장소 |
| 매칭 신청 | `/apply/1~4`, `/apply/confirm`, `/apply/done` | 4단계 신청서(기본 정보·취향·나·상대), 제출 전 확인, 신청 완료 |
| 내 약속 | `/appointments` | 신청 상태 |
| 프로필 | `/profile` | 닉네임 수정, 저장 수, 신청 상태, 데모 데이터 초기화 |

## 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 0~1 | 화면과 흐름, 브라우저 저장소 데모 | 완료 |
| 2 | Supabase 연결: 이메일 코드 로그인, 약관 동의, 로그인 사용자별 저장·신청, 접근 규칙, 본인확인 상태(흉내) | 로컬 완료 (운영 연결 전) |
| 3 | 운영자 소개·수락·일정/장소 합의 | 예정 |

## 아직 하지 않는 것
채팅, 알림, 후기, 인용 게시물, 영문 온보딩

## 미확정 사항
시안 대비 차이와 임시 가정값(파일럿 역, 시간대, 글자 수 제한 등)은 [design-notes.md](design-notes.md)에 있습니다.
